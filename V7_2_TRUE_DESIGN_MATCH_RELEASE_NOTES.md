# ShePlates v7.2.0 — True Design Match

This release corrects the gap between the approved UI concept and the runnable product. It is a visual-only pass: commerce, authentication, agent tools, Supabase integration, schedules, orders, payments, roles and permissions are unchanged.

## What changed

- Rebuilt the public landing structure to match the approved premium local-commerce concept rather than applying only a CSS skin.
- Removed the dominant orange hero; moved to a light, editorial, local-food presentation with restrained green accents.
- Original ShePlates logo asset remains unchanged.
- Added a human-designed responsive hero, glass location/search control, trust row, category strip, popular product cards and editorial CTAs.
- Refined the logged-in shell, marketplace toolbar, category chips, product cards, tables and metrics to use the same design system.
- Changed Vendor / Operations / Super Admin navigation from a heavy dark sidebar to a light, glass-backed enterprise sidebar with green active states.
- Kept glass material intentional: top navigation, menus, modal sheets, notifications and She Agent. Product/content cards remain mostly opaque for readability.
- Preserved the floating She Agent orb and glass workspace on mobile and desktop.
- Kept mobile safe-area, portrait modal and bottom-dock fixes from earlier releases.

## Important testing note

Browser zoom changes the perceived scale dramatically. Test at 100% browser zoom (Cmd+0 on macOS, Ctrl+0 on Windows) before comparing against the design reference.
